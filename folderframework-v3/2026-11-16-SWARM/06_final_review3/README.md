# 06_final_review3 — Phase 4: subset synthesis

3–5 participants only: the strongest domain experts + one synthesizer. Produce a **single** consolidated document, `SYNTHESIS.md`, that:

- Merges the best ideas from `04_final_review/` + `05_final_reviewv2/` (cite sources inline).
- **Explicitly discards** the rest — one line per discarded idea with the reason.
- Lists residual risks with risk rating (High/Med/Low).
- Records conflict resolutions: disagreements are settled by **evidence weight + risk**, not voting; the synthesizer documents each decision.

Output here feeds `07_final_review4/` — which is the plan a human/merge-agent approves or rejects.
