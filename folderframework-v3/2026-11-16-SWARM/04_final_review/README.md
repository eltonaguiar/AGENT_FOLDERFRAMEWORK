# 04_final_review — Phase 2: first peer review

One file per agent: `agent_<name>_final_review.md`. Review your own work **and at least two other agents'** `03_DONE/` deliverables. Reviews without evidence are invalid.

Template:

```markdown
# Final Review – Agent X
**Date:** YYYY-MM-DD · **Own deliverable:** 03_DONE/<DOMAIN>/<file>

## What I agree with
- (claim, source file, why)

## What I disagree with (and why, with evidence)
- (claim, counter-evidence: path / SHA / URL / query result)

## Missing evidence / open questions
- (what would settle it and how to get it)

## Proposed changes to my own work after reading others
- (concrete edit to own 03_DONE file)

## Risk rating for each proposed fix
| Fix | Risk (High/Med/Low) | Why |
|-----|---------------------|-----|
```
