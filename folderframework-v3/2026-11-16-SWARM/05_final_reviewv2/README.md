# 05_final_reviewv2 — Phase 3: second pass

After reading all `04_final_review/` files, each agent writes one **short** `agent_<name>_reviewv2.md` containing only:

1. **Revised recommendations** — what changed from your Phase-1/2 position, and which review changed it (cite the file).
2. **Explicitly resolved disagreements** — pairs of (claim A, claim B) → resolution → evidence that settles it.
3. **Remaining blockers** — anything still undecidable, with the specific evidence that would unblock it.

No re-litigating settled points. If you stand by a disagreement, say so once, with evidence weight + risk as the justification.
